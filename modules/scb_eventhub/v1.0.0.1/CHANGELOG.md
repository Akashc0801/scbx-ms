## [1.0.0.1] - 2026-04-15

### Changed

- Integrated scb naming module (v1.0.0.1) for consistent resource naming and tagging.
- Removed AVM references and replaced with SCB conventions.
- Name and location are now generated by the naming module instead of being passed directly.

## [1.0.0.0] - Initial Release

### Added

- Create Azure Event Hub Namespace Terraform Module.
- Support for Event Hubs within namespace with partition_count, message_retention, and capture.
- Support for Customer Managed Keys.
- Support for Private Endpoints with managed and unmanaged DNS zone groups.
- Support for Diagnostic Settings.
- Support for Managed Identities (System and User Assigned).
- Support for Role Assignments at namespace and event hub level.
- Support for Management Locks.
- Support for Network Rule Sets.
