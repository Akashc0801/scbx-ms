# Example: Policy Exemption

This example demonstrates how to use the `scb_policy_exemption` module to create a policy exemption at the resource group scope.

## 📁 Files in this Example

- **`main.tf`**: Example policy assignment and exemption
- **`variables.tf`**: Input variables for customization
- **`outputs.tf`**: Example outputs
- **`terraform.tf`**: Provider requirements

## 🚀 Quick Start

1. Initialize Terraform
2. Plan the deployment
3. Apply the configuration

## Notes

- Update the policy definition and parameters to match your organization’s requirements.
- Ensure you have sufficient permissions (Policy Contributor or Owner) at the target scope.
